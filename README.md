# StudentAbroadProject

Official website for StudentAbroad.

## Про проєкт
StudentAbroad — це платформа, яка допомагає студентам знаходити та ділитися програмами навчання за кордоном.

## Технології
- **Frontend**: HTML / SCSS / JS
- **Backend**: Python (Django)
- **Database**: PostgreSQL
- **Deployment**: Nginx + Gunicorn на Ubuntu VPS (OVHcloud)
- **Захист**: Cloudflare Turnstile

## Деплой
Інструкції з налаштування сервера та деплою знаходяться у файлі `deployment/README.md`.
